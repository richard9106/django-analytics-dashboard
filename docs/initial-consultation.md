# Initial consultations and client forms

Initial consultation is a session purpose, separate from the in-person/video/phone
format. New consultations suggest 15 minutes; therapists may choose 10 minutes or
another duration. Manually selected duration is retained when moving the start time.
Existing appointments remain Standard session. Calendar, Agenda, List, exports and
Google Calendar descriptions identify initial consultations.

The client overview shows its assigned therapist's consultations (all practice
consultations for owner/admin), with Not scheduled, Scheduled, Completed or the last
cancelled/no-show state. A cancellation is not completion. This is a visible onboarding
step; it does not block scheduling or retrospectively classify old sessions.

Registered clients can submit an Initial consultation request through their portal.
Requests retains its normal review/resolve actions and provides Schedule consultation
with the client and purpose preselected. The request is resolved explicitly after
arranging the session. Public bookings remain ordinary booking requests.

The existing question templates, assignments and responses are labeled Client forms
in navigation and Form templates in the library. Their URLs and stored data remain
unchanged. Clinical Intake Note remains a separate documentation type.
